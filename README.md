# ClawdStudio

An Android-first Flutter workspace intended to make the real [Clawd-Code](https://github.com/GPT-AGI/Clawd-Code) Python coding agent easier to use from a phone.

> **Status: UI foundation plus an initial Termux transport diagnostic.** This does not yet run the Clawd-Code agent loop, configure an AI provider, edit workspaces, or perform GitHub operations.

## Development

Install the current stable Flutter SDK using the [official Flutter instructions](https://docs.flutter.dev/get-started/install), then run:

```sh
flutter pub get
python3 tool/configure_android.py
dart format --set-exit-if-changed .
flutter analyze
flutter test
flutter build apk --debug
```

The Android platform folder is generated by Flutter tooling in CI. If missing locally, run `flutter create --platforms=android --project-name=clawd_studio --org=dev.clawdstudio .` before `tool/configure_android.py`.

## Termux diagnostic setup

1. Install Termux from an official source and open it once.
2. In Termux, edit `~/.termux/termux.properties` and set `allow-external-apps=true`; restart Termux.
3. In Android Settings, grant ClawdStudio the **Run commands in Termux environment** permission.
4. Open Engine in ClawdStudio, tap **Check Termux setup**, then **Run safe diagnostic**.

The diagnostic runs a fixed `printf` command only. It does not accept shell commands from the AI or user. Termux can execute commands with Termux's privileges, so keep this permission enabled only if you understand and want this integration.

Read [the runtime spike](docs/ENGINE_SPIKE.md), [architecture](docs/ARCHITECTURE.md), [status](docs/STATUS.md), [testing](docs/TESTING.md), and [security notes](docs/SECURITY.md).
