# ClawdStudio

An Android-first Flutter workspace intended to make the real [Clawd-Code](https://github.com/GPT-AGI/Clawd-Code) Python coding agent easier to use from a phone.

> **Status: early UI foundation only.** This repository does not yet contain an engine bridge, provider integration, workspace operations, or a usable coding-agent loop. The screen intentionally reports these capabilities as unavailable.

## Development

Install the current stable Flutter SDK using the [official Flutter instructions](https://docs.flutter.dev/get-started/install), then run:

```sh
flutter pub get
dart format --set-exit-if-changed .
flutter analyze
flutter test
flutter build apk --debug
```

The Android platform folder is generated by Flutter tooling in CI. For local builds, run `flutter create --platforms=android .` once if the platform directory is absent.

## Security

Never commit provider keys, GitHub tokens, signing keys, or user workspaces. The app must not claim a provider, engine, or repository is connected unless an actual check succeeded. See [security notes](docs/SECURITY.md).
